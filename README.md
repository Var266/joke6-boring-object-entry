## The entry

Running the program produces a single one-line review (113 characters) of the
most boring object in the house — the dustpan:

> Dustpan review: it sweeps up all the dirt, then leaves one thin line behind and guards it like a family heirloom.

Why this lands: everyone who has swept a floor knows the dustpan's one
unforgivable habit. It gathers nearly everything, then strands exactly one
thin line of dust on the floor — and no amount of re-sweeping ever picks that
line up. The review frames that leftover sliver as a treasure the dustpan
refuses to surrender, which turns a dull chore detail into the joke.

## Run

```sh
node main.ts && cat /output/entry.txt
```
