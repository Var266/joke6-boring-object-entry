Entry for the make.fun bounty **[The Most Boring Object, Reviewed in One Line](https://make.fun/c/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3)**.

## What it does

`main.ts` writes a single one-line review (113 characters) of the dullest
everyday object to `/output/entry.txt`:

> Dustpan review: it sweeps up all the dirt, then leaves one thin line behind and guards it like a family heirloom.

The joke comes from a real, recognisable detail: a dustpan always leaves one
thin line of dust behind, no matter how carefully you sweep.

## Run

```sh
node main.ts && cat /output/entry.txt
```
